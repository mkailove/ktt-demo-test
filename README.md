# 快团团素材生成器

本地网页版单商品海报编辑器。第一版只使用根目录的 `index.html`，无需安装依赖或启动服务。

## 使用方法

1. 用 Windows 桌面版 Chrome 或 Edge 直接打开 `index.html`。
2. 修改商品信息与卖点，上传一张商品主图，以及团长二维码或商品码。文件选择不限制格式、体积、像素数或二维码形状；当前浏览器能解码的图片才可使用。
3. 选择“居中促销”“左图清单”或“大图爆款”，右侧预览会随编辑更新。窄屏下预览位于编辑区下方。
4. 点击“导出 PNG”，下载一张 720 × 1280 像素海报。文字过长、价格无效或缺少图片时，按页面提示修改后再导出。
5. 点击“恢复示例”会立即清空已上传图片并重置文字。刷新页面也会恢复默认示例，不保存草稿。

图片与文字只在浏览器本地处理，不上传到服务器。导出结果由浏览器保存到默认下载位置。

## 验证

在项目目录运行 `node --test`。手工检查按 [验收清单](tests/acceptance.md) 执行，需分别在 Chrome 和 Edge 打开本地文件，并用手机扫描导出图片中的测试二维码。临时素材与导出结果放在 `work/`；该目录已被 Git 忽略。

当前实现的自动化测试已通过；Chrome、Edge 的完整手工验收与真机扫码尚未记录，具体状态见验收清单。二维码外围不额外填白，正式使用前请按 AC04 检查导出图片是否可扫。

当前需求与尺寸规则见 [产品需求](docs/prd-example.md)；[实施计划](docs/implementation-plan.md)仅供回看开发过程。公开发布需按 [项目规则](AGENTS.md) 单独确认。
